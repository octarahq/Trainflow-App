## About

`TrainFlow App` is the official native Android application for **TrainFlow**, the real-time tracking and visualization platform for the French national rail network (**SNCF**).

## Features

- **Interactive Live Map**: Track trains moving across France in real time with category filters (TGV, TER, Intercités, Transilien) and live speed tracking.
- **Network Status & Delays**: View global traffic statistics (punctuality rate, active trains, total delays) and filter delayed trains by train number, type, or station.
- **Trip Tracking & Live Notifications**: Save journeys to receive live status updates (platform assignments, delays, terminus arrival notifications).
- **Ticket Scanner**: Import tickets to follow and get live updates on your train's status.
